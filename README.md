# DANA Sweet Studio

Статический демонстрационный сайт-каталог для портфолио Liberté Digital. HTML, CSS, JavaScript без сборки и зависимостей. Открыть index.html через любой статический сервер. Публикуемая папка — корень проекта.

## Содержимое

9 известных позиций, фильтры, избранные трайфлы, история студии, сотрудничество, заказ и доставка, контакты. Полный будущий каталог — около 15 позиций. Корзины, оплаты и отправки сообщений нет. Кнопки готовят редактируемый текст и ссылку WhatsApp на предоставленный пользователем номер +7 999 309-96-46. Автоматической отправки нет.

## До коммерческого запуска

- Получить Instagram. WhatsApp предоставлен пользователем: +7 999 309-96-46.
- Город бесплатной доставки: Нальчик. Уточнить детали зоны доставки и точку самовывоза.
- Получить оригинальный логотип и фото изделий.
- Подтвердить названия всех позиций, составы, аллергены, точные веса, цены и сроки хранения.
- Согласовать формулировку отмены и переноса: в анкете указано, что они не допускаются; на публичной демонстрационной странице это не оформлено как юридическое правило.
- Заменить демонстрационные изображения и снять демомаркировку только после согласования.

## Фото

Иллюстрация создана встроенным ImageGen, не реальные изделия студии. Промпт и происхождение указаны в ASSETS.md. Шрифты загружаются с Google Fonts; есть системные запасные шрифты.

## Развёртывание

GitHub Pages: Settings → Pages → Deploy from a branch → main / root. Cloudflare Pages: подключить этот отдельный репозиторий, без команды сборки, папка результата `/`. Не изменять sklad-course и buhgalter-course.
